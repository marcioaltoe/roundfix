## Failures

### Default static gate fails with global Git signing enabled

Expected: `rtk make verify` passes the full repository gate.

Actual: `rtk make verify` exited 2 during `go test ./...`. Six tests failed while creating commits in temporary repositories:

- `internal/preflight`: `TestExecGitRunnerParsesStdoutSeparatelyFromStderr`
- `internal/preflight`: `TestExecGitRunnerReportsStderrDetailOnFailure`
- `internal/preflight`: `TestExecGitRunnerDisablesFSMonitorPerInvocation`
- `internal/preflight`: `TestExecGitRunnerStatusDetectionSurvivesFSMonitorNoise`
- `internal/daemon`: `TestGitCommitterExcludesProjectConfigFromBatchCommit`
- `internal/daemon`: `TestSnapshotDiffCommitStagesOnlyAgentChangesInRealRepo`

Observed error:

```text
error: gpg failed to sign the data:
fatal: failed to write commit object
```

Repro:

```bash
rtk make verify
```

Control run:

```bash
rtk env GIT_CONFIG_COUNT=1 GIT_CONFIG_KEY_0=commit.gpgsign GIT_CONFIG_VALUE_0=false make verify
```

The control run passed, which points to inherited global Git signing config in temp-repo tests rather than an ACPX migration behavior failure. The latest default report still fails, so this QA gate blocks.
