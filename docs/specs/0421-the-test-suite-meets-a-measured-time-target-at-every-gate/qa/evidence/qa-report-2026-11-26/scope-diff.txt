 ## Language
 
+**Gate Time Target**:
+The approved time objective of a repository verification gate on its named machine, judged by its measurement window or lab protocol ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Timeout, suite budget, enforced number

+**Gate Time Report**:
+The elapsed time of one verification gate compared with its approved target or recorded number, without failing that execution for time alone ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Time verdict, timeout error, benchmark
+
+**Complete Suite Run**:
+The run of every package test with fresh results before a Spec's pull request opens, carried by the repository gate after its archive commit ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Task verification, selected package run, full contract run
+
+
+**Gate Time Rule**:
+The decision that fixes each gate's machine, measured number and verification shape after its measurement window, and permits a rise or a change of shape only by the maintainer's decision on a Measured Dossier ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Timeout increase, suite budget, automatic relaxation
+
+**Measured Dossier**:
+The evidence for a large new feature's Rule Challenge: its gate time before and after on the named machine, work already cut, merged or moved, and the measured new number, put to the maintainer only in the feature's Idea or PRD ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Exception request, corrective overrun, runtime waiver
+
+**Release Provenance**:
+The proof that a release commit is the squash merge of one pull request into main whose branch held main's tip, has the same tree and whose latest Verification gate check passed; a pushed tag must point at that release commit ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
+_Avoid_: Repeated suite, trusted tag, publication preflight
