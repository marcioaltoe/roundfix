The QA harness exported synthetic Git author/committer identities while creating temporary repositories. They propagated into tests and overrode deterministic fixture identities, changing Baseline plan digests and a fixed follow-up Git head. The first complete sample failed; the second was interrupted once both named tests passed in a clean-identity diagnostic. The owned process group exited 130 and no tracked descendant remained running. These attempts are excluded from timings and acceptance. Fixture Git identity is now supplied only with git -c arguments when creating the temporary repository. No product assertion, golden or source changed.
