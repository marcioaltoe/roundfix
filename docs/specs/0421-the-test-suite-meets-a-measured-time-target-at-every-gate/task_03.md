# Task 03: A Task settles on the light checks, the Complete Suite Run gets its home, and each gate reports its time

## Overview

This Task delivers `_techspec.md` → Build Order 3. `make verify-changed`, the one command the Project Config names, reads a package plan: at a Task settlement it runs format, vet, build, the selected Repository Contract Tests and the comparison of the coverage record, and no package test; for the candidate of a Spec, which adds an Archive Record, it runs every package once with fresh results, the Complete Suite Run; otherwise it runs the packages a change reaches. The repository's checks of its own rules and records become `//verify:always` contracts, the CLI package is split into shards for the parallel jobs task_04 wires, and a new repository tool, `cmd/gate-time`, prints each gate's time against the Gate Time Target it reads from one reference file. It is verifiable on its own through the selector's and the tool's tests, the Makefile tests that run the real recipes with a stub `go`, and the contracts over the moved tests and the targets.
