# Task 04: Continuous integration runs only for a pull request and in parallel jobs, a release proves its provenance, and two time rules are retired

## Overview

This Task delivers `_techspec.md` → Build Order 4. The verification workflow runs only for a pull request, as five parallel jobs on `macos-26` gathered by the job that keeps the required check's name, and every Repository Contract Test runs once for each pull request. The release's job `verify` runs no test and proves the Release Provenance of the release commit before anything is built, as the answer on the release grants. The suite-time budget leaves the `Makefile`, ADR-0453 supersedes ADR-0387 and amends six decision records, and the glossary, the repository's guide and the release runbook say what each gate runs. It is verifiable on its own through the workflow and release-harness tests, the decision-record contract and the glossary and documentation contracts.
