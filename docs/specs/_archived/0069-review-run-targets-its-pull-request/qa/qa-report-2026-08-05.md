## Findings

### F-001 — Exit-2 refusal creates the Artifact Directory while reporting no side effects

- Impact: `Trust-Damage`.
- Actor and step: a Roundfix operator runs `fetch` from a branch that does not
  match the supplied PR Head Branch, with a previously absent explicit
  Artifact Directory.
- Expected: Preflight exits 2 before any write; the directory remains absent.
  This is required by PRD Core Feature 1, Goal 1, Task 01 Requirement 4, and the
  Skill's “refusal creates no Run and has no side effects” contract.
- Actual: the command exits 2 and prints `Roundfix did not create a Run, fetch
  Review Source issues, start an Agent, commit, or push.`, but creates the
  directory with mode 755.
- Reproduction from the public entry point:

  ```text
  $ rtk ls -ld qa-probe-artifacts
  exit 1: No such file or directory

  $ rtk <build>/bin/roundfix fetch --source coderabbit --pr 123 \
      --artifact-dir /private/tmp/roundfix-qa0069.OpMsQD/qa-probe-artifacts \
      --base-repo owner/project --head-repo owner/project \
      --head-branch ma/feature-review --no-input
  exit 2: Preflight failed ... No side effects ...

  $ rtk ls -ld qa-probe-artifacts
  exit 0: 755  qa-probe-artifacts/
  ```

- Independent confirmation: the same behavior occurred with the first absent
  `.artifacts` path. Branch, HEAD, and porcelain remained unchanged, isolating
  the divergence to the directory write.
- Affected row: 3.
- Root cause: not diagnosed in this report-only gate.
