- Impact: Blocks-Completion.

  journeys settle their authored pass/partial/fail/missing/unreadable verdict.

  `qa-report-2026-01-01.md`; the Daemon's newer
  `qa-report-2026-08-11.md` seed remains without a verdict and wins recency,
  so the CLI settles `unreadable`. Both verification tiers exit 2.
- Reproduction: run
  `qa/evidence/2026-08-11-spec-0080/R04-minimal-reproduction.sh`; the focused
  `TestRunImplementQAVerdictMatrix/pass` exits 1. The full gate shows the same
  root cause across auto-push, attach, QA-only, external-root, branch, and
  interactive-input journeys.
- Root cause: Task 03 updated the Daemon-unit fake for seeded-report completion
  but left `internal/cli/implement_test.go:754-765,799` on the pre-seed fixed
  filename. The writer/selector behavior is at
  `internal/daemon/task_engine.go:1798,2017-2040` and
  `internal/spec/qa.go:34-72`.
- Affected rows: R03 and R04.
- Required before rerun: make every public CLI QA fake complete or remove the
  exact `Seeded QA Report:` path, preserve missing/unreadable cases, then run a
  cold `make verify`, the failed flow, and one adjacent blocking-stage canary.
