 Roundfix picks up Work Items — Review Issues from pull request reviews and Tasks from Spec Task Graphs — resolves them through the user's selected ACP Runtime, and pushes only when nothing unresolved remains. This glossary defines the product language for that loop; the terms under Adopter decisions describe repositories the Context-Driven Baseline configures, not Roundfix itself.
 
 ## Language
+
+**Language Rule**:
+The Baseline rule requiring English for code and infrastructure names unless a Code Language Exception is declared, and the repository's Reader Language for text its product's users read ([ADR-0454](docs/adr/0454-code-is-written-in-english-and-each-repository-declares-its-reader-language.md)).
+_Avoid_: Language preference, bulk rename policy
+
+**Reader Language**:
+The language a repository declares for what its product's users read, including screens, messages, e-mails, PDFs, user documentation and MCP tool names, descriptions and parameters; Specs, ADRs, agent guides, commits and pull requests keep their existing language ([ADR-0454](docs/adr/0454-code-is-written-in-english-and-each-repository-declares-its-reader-language.md)).
+_Avoid_: Code language, agent language
+
+**Untranslated Term**:
+A business term without a faithful English translation that keeps its original form inside an English name: an official acronym as it is, another term without accents, and the rest of the name in English ([ADR-0454](docs/adr/0454-code-is-written-in-english-and-each-repository-declares-its-reader-language.md)).
+_Avoid_: Arbitrary foreign name, untranslated identifier
+
+**Name in Code**:
+The name a term's Glossary Definition records when its code name differs from the term: the chosen English translation or the original form kept without accents ([ADR-0454](docs/adr/0454-code-is-written-in-english-and-each-repository-declares-its-reader-language.md)).
+_Avoid_: Display label, alternate glossary
+
+**Code Language Exception**:
+A repository's declaration of the language and the source of its owner's decision to keep an existing codebase's code and infrastructure names in that language. It covers only the codebase that existed when the owner decided, never a new one; the Reader Language and Name in Code still apply ([ADR-0454](docs/adr/0454-code-is-written-in-english-and-each-repository-declares-its-reader-language.md)).
+_Avoid_: Reader language override, new codebase language choice
 
 **Gate Time Target**:
 The approved time objective of a repository verification gate on its named machine, judged by its measurement window or lab protocol ([ADR-0453](docs/adr/0453-two-time-rules-are-retired-until-the-gate-time-rule-is-written.md)).
