# Task 01: The Baseline carries the Language Rule and asks each repository its Reader Language

## Overview

This Task delivers `_techspec.md` → Build Order 1: the `core` module gains the Language Rule as a new rule of four mandatory clauses, the Reader Language becomes a required decision rendered in the opening lines of the agent-instructions guide, and the canonical-terms clause of the domain guide carries the Name in Code by insertion. The answer fixtures of the tests that list every required decision gain the new answer, the derived Baseline files and this repository's guides are regenerated by the sanctioned commands, the published Decision Document gains the decision, and ADR 0454 records the whole design. It is verifiable on its own: every built-in profile renders the rule, an update without the answer stops and names the decision, and this repository's Managed Refresh leaves it current.
