clause.python.change-dependencies-through-uv [mandatory] Change dependencies only through uv: `uv add`, `uv add --group dev`, `uv remove` and `uv lock --upgrade-package`. Commit `pyproject.toml` and `uv.lock` together, and never install into the project environment with `pip`.
clause.python.run-tools-through-uv [mandatory] Run Python, pytest, ruff and every other project tool through `uv run`, so each uses the locked project environment and the Python version the project pins, never a globally installed interpreter or tool.
clause.python.sync-the-locked-environment [mandatory] Create a worktree's or CI job's environment with `uv sync --frozen` and the development group the gate needs, so it installs exactly what `uv.lock` records; a step that must also refuse a lockfile that no longer matches `pyproject.toml` uses `--locked` instead.
clause.python.check-the-lock-offline [mandatory] The repository Verification checks the lockfile with `uv lock --check --offline`: it compares `uv.lock` with `pyproject.toml` from local files alone, fails when they no longer match, and needs no network or cache, so it runs inside a Run as in CI.
clause.python.iterate-with-focused-commands [mandatory] Use focused commands such as `uv run pytest <node id>`, `uv run ruff check <path>` and `uv run ty check <path>` while iterating, then run the selected repository Verification.
clause.python.ruff-findings-fail-the-gate [prohibited] Do not hide a ruff finding: never pass `--exit-zero`, add a blanket `# noqa`, or widen the ruff configuration to make a finding disappear. A `# noqa` names the rule code it silences and the reason.
clause.python.type-check-with-ty [mandatory] The repository Verification type-checks the package and its tests with `uv run ty check --error-on-warning`, ty being a development dependency. Do not hide a ty diagnostic: never pass `--exit-zero` or `--exit-zero-on-warning`, add a blanket `# ty: ignore` or `# type: ignore`, or widen the ty configuration to make a diagnostic disappear. A suppression names the rule it silences and the reason.
clause.python.select-a-new-test-by-its-node-id [mandatory] A Task Verification selects a new test by its pytest node id, such as `tests/test_report.py::test_totals`, and never passes that test's file or directory in the same command. pytest collects a node id once when another argument already contains it and exits 0 even before the test exists, so the command could never fail before the work; a missing node id alone exits 4 and an empty selection exits 5. `roundfix spec check` reports a command that names a test both ways.
clause.python.keep-tests-hermetic [mandatory] Keep tests hermetic: set or clear with `monkeypatch` every environment variable the code under test reads, write only under `tmp_path`, and never read the host's credentials, home directory, network or tool state.
clause.python.outside-data-skips-by-name [mandatory] A test that needs data from outside the repository, such as a mounted drive or a credentialed service, calls `pytest.skip` with a reason that names the environment variable or path it lacks, so the selected Verification passes on a machine without that data. A Task Verification never depends on such a test.
clause.python.exercise-every-platform-branch [mandatory] When a change touches code that branches on the operating system, such as on `sys.platform`, `os.name` or `platform.system()`, exercise every branch it names: test each one with `monkeypatch` over the value the code reads, or run `uv run ty check --python-platform <platform>` for each platform it names, because a test run on the host executes only the host's branch.
clause.python.keep-entry-points-thin [mandatory] Keep each entry point thin, whether a console script, a web application factory or a worker's start-up: it reads its input and calls behavior that lives in the package. Test behavior through the package and the entry point's observable contract: for a console script, standard output, standard error and the exit code it raises with `SystemExit`; for a web application or a worker, the responses or messages it produces.
