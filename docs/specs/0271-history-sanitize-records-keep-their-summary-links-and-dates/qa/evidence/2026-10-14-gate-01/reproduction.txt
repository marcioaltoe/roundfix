Public user-flow fixture: public-flows.py.txt. It uses only a temporary repository and HOME, invokes ./bin/roundfix by symlink to the audited binary, and waits for each child command.
Support module: copy report-helper.py.txt to /tmp/roundfix-0271-qa01-report.py and create /tmp/roundfix-0271-qa01-state.json with root (current repository), evid (new evidence directory), tmp (new temporary directory), head, base and version. The finish helper updates the planned report; for standalone fixture reproduction it may be replaced with a print-only finish function. Build the audited binary with make build first.
Comparator: create a detached temporary worktree of this same repository at the delivery base, run make build there, and write <tmp>/base-state.json with base and checkout. Then execute comparison.py.txt. Remove the temporary worktree after completion. Exact commands and output from this observation are in comparison.log and delivery-base-build.log.
Test command strings and exit codes are in test-results.json; full outputs are in archive-tests.log, task-verification.log and docs-checks-final.log. Run them foreground with a temporary HOME and no provider variables. Keep repository bytes idle throughout test execution; capture output under the temporary directory and copy it afterwards.
