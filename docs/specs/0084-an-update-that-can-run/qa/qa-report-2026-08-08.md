  requirement that test encoded. But `docs/references/coverage-record.json` still
  records the name, and no Spec 0084 commit touches that file

  only source of truth, so a deliberately retired test reads as a coverage
  regression.

  `go test ./internal/baseline/ ./internal/cli/`, which passes. No Task ran
  `make verify` or `./internal/spec`, and the Pull Request's green verification
  check ran on `71babdae`, before task_01.
