Archived Item Resume entry:

The start of a new Delivery Queue item whose continued Item Branch already archives its Spec in a commit proven to be an exact archive of it: the item enters review with its head as the candidate, without Delivery Revalidation, an Implement Run or a new archive. An item branch whose archive cannot be proven parks as `archived-item-unproven` (ADR-0312).
_Avoid_: Archived retry, requeue

A Delivery Retry of that park returns the item to `queued` and counts a retry, so the owner proves the branch again.
