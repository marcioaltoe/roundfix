# Task 03: The user guide and the Roundfix skill describe a product without the Linux Lane

## Overview

This Task delivers `_techspec.md` → Build Order 3 and the Coverage Review of API Contract 13. The `deliver`, `doctor` and configuration pages of the user guide and both copies of the Roundfix skill's `deliver`, `setup`, `implement` and `runtime` references lose every description of the lane, its command, its check and its codes; the configuration page and the `setup` reference list the two keys among the deprecated ones with their warning; and the release runbook says that the release verifies on a macOS runner before it validates the version. The skill mirror, the skill's version and the Behavior Surface Record are regenerated by their commands, and the two surfaces of the release runbook carry their Coverage Review. It describes what task_01 and task_02 made the product and the release do, so an operator who reads the guide or the skill is never sent to repair Docker. It is verifiable on its own through a documentation contract test and the existing skills, coverage and contract-declaration tests.
