## Findings

### F-001 — Baseline rejects a real pre-0085 archive above the carrier-byte budget

- Impact: Blocks-Completion.
- Actor and journey: fleet maintainer, QA-02, applying the current Baseline to a
  disposable copy of an adopted repository.
- Expected: the 173 archived files move from `docs/specs/_archived/` to
  `docs/history/specs/`, preserve their byte identities, and a second run reports
  no relocation.
- Actual: apply exits 2 before mutation because the 10.8 MiB archive crosses the
  repository carrier limit of 8,388,608 bytes. The history-move ledger was
  designed to carry identities rather than content, but the public apply path
  still rejects this measured fleet tree on cumulative carrier bytes.
- Reproduction: clone `/Users/marcio/dev/conexus` at `5a200bb` with
  `git clone --local --no-hardlinks`; run the command recorded under QA-02.
- Evidence: QA-02 command transcript, source count, pre-migration manifest
  identity, and post-refusal clean-tree checks above.
- Affected rows: QA-02. QA-09 remains independently runnable for its negative
  guarantees.

### F-002 — Baseline hides history moves, liveness decisions, and collisions

- Impact: Trust-Damage.
- Actor and journeys: maintainer, QA-03 and QA-04, previewing, applying, and
  rerunning Baseline on a disposable current-build clone.
- Expected: every relocation appears in plan/apply output; retained orphan
  reviews are reported live with a reason; an occupied destination refuses that
