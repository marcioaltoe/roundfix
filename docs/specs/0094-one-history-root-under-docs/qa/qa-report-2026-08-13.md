### F-001 — Shipped carriers contradict the built-in archive destination

Impact: **Trust-Damage**. A maintainer reading `roundfix archive --help` is told
that the built-in Spec Root archives to `_archived/specs/<slug>/`, while the
same binary actually prints and writes `docs/history/specs/<slug>/`. The
embedded Source Baseline's `docs/agents/spec-routing.md` repeats the old
location, so Core Feature 10's every-carrier promise is also unmet.

- Actor and step: maintainer checks command help before archiving; an adopting
  repository consumes the shipped Source Baseline carrier.
- Expected: every shipped carrier names `docs/history/specs/` for the built-in
  root.
- Actual: `internal/cli/archive.go:22` and the embedded Source Baseline
  `docs/agents/spec-routing.md:22` name `_archived/specs/`.
- Reproduction: run `rtk ./bin/roundfix archive --help`, then `rtk rg -n
  '_archived/specs' internal/cli/archive.go
  internal/baseline/assets/source-baselines/baseline.standard-typescript-monorepo-0.0.1/corpus/docs/agents/spec-routing.md`.
- Affected rows: QA-001 and QA-010.
- Evidence: [command evidence](evidence/2026-08-13-gate/command-evidence.md#documentation-and-vocabulary-sweep).
