### F-06 — Asset-sync Git fixture races temporary-directory cleanup

- Impact: `Blocks-Completion`
- Actor and step: QA operator, mandatory `make verify` static gate
- Expected: the repository's only completion gate passes completely and
  deterministically before a public binary is used for live journeys.
- Actual: 2,199 tests passed, but the asset-sync provenance test failed while
  Go removed a temporary Git repository. Fifty exact repetitions reproduced
  the race twice; each failed repository retained
  `.git/objects/info/packs`.
- Root cause: fixture Git commands disable `core.fsmonitor` but allow Git
  automatic background maintenance to outlive the command and recreate files
  while `t.TempDir` removes the repository. Disabling only
  `maintenance.auto` for diagnosis passed 100/100.
- Reproduction:
  `rtk proxy go test -count=50 ./internal/baseline -run
  'TestAssetsSyncProvenanceAndPreMutationRefusals/dirty_or_untracked_checkout'`
- Evidence:
  `qa/evidence/2026-07-25-guidance-composition/command-evidence.md`
- Affected rows: SG-01 directly; every other planned row was skipped by the
  mandatory static-gate stop.
- Required repair: make the temporary Git fixtures own and synchronously close
  all Git background work at the fixture boundary, then rerun unmodified
  `make verify` and the complete LIVE-01 through LIVE-03 matrix from one fresh
  binary.
