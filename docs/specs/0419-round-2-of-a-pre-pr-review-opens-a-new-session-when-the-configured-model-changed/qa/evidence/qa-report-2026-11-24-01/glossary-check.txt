**Reviewer Lineage**:
The at-most-two review rounds of one delivery candidate, where round 2 reviews only the delta since round 1 with round 1's findings and dispositions, continuing the same Agent Session when the runtime can resume it and the review profile still names the Agent Model that session was opened with, and otherwise opening a new one with the same prompt. A merge of the default branch keeps it, and the delta then starts from the round-1 head carried onto the new merge base, or from its Conflicted Carry when that merge conflicts. It may include one Correction Review when every standing round-2 finding was fixed ([ADR-0197](docs/adr/0197-a-pre-pr-reviewer-lineage-spans-at-most-two-rounds.md), [ADR-0286](docs/adr/0286-a-fixed-round-2-finding-gets-one-correction-review-of-its-fix.md), [ADR-0366](docs/adr/0366-a-conflict-free-merge-of-the-default-branch-is-a-review-delta-and-a-segment-is-measured-from-its-effective-base.md), [ADR-0391](docs/adr/0391-a-conflicting-merge-of-the-default-branch-is-a-review-delta-from-its-conflicted-carry.md), [ADR-0451](docs/adr/0451-round-2-of-a-pre-pr-review-opens-a-new-session-when-the-configured-model-changed.md)).
