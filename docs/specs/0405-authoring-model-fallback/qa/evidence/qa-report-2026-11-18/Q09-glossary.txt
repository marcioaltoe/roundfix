Authoring Fallback: The fallback model and reasoning effort an Authoring Phase declares for its Author Subagent when the declared model's own usage limit runs out. It holds for later phases of that Spec in the same repository whose declared model matches that limit; the next Spec starts on its declared model ([ADR-0427](docs/adr/0427-an-authoring-phase-falls-back-to-its-declared-fallback-when-the-declared-model-s-usage-limit-runs-out.md), [ADR-0428](docs/adr/0428-a-spec-whose-phase-fell-back-keeps-the-fallback-for-the-limited-model-until-the-spec-ends.md)).
_Avoid_: Retry model, fallback chain, backup preset
Authoring Model Declaration: The `skills.authoring` section of Project Config that declares, per Agent harness, the model and reasoning effort of each Authoring Phase and of research sweeps; each Authoring Phase may declare a fallback model and reasoning effort. Roundfix applies no model name by itself, the section is ignored in User Config, and a repository that declares nothing keeps the shipped skills unchanged. When installed authoring skills have no declaration, the Doctor Command reports `authoring-models: warn` and the Update Check reports `authoringModels.state` `undeclared`, each with the Recommended Authoring Declaration. `roundfix skills install --target project` and `roundfix baseline update` apply it, and `roundfix skills check`, the Doctor Command and the Update Check warn when the installed files do not match it ([ADR-0401](docs/adr/0401-each-authoring-phase-runs-on-the-model-its-repository-declares.md), [ADR-0415](docs/adr/0415-doctor-and-the-update-check-recommend-an-authoring-model-declaration-when-none-is-declared.md), [ADR-0430](docs/adr/0430-the-recommended-authoring-declaration-carries-a-fallback-for-each-authoring-phase.md)).
_Avoid_: Model preset, skill model setting, phase profile
Author Subagent: The subagent that installation generates for one declared Authoring Phase, `roundfix-<phase>-author`, on the declared model and reasoning effort. An authoring skill the session activated hands its phase to it with the model and effort `roundfix phase model` or `roundfix phase fallback` prints; it cannot ask the user, so the session gathers the decisions first and it returns its open questions instead of guessing one. On the fix or refactor route, `write-techspec` and `write-tasks` run the phase in the session and start it only when the user's request or one of the user's answers asks for it. It is a subagent of the Agent harness session and never the Agent of a Run, and it ends no session at a Phase Boundary ([ADR-0401](docs/adr/0401-each-authoring-phase-runs-on-the-model-its-repository-declares.md), [ADR-0408](docs/adr/0408-a-repository-that-publishes-an-authoring-skill-receives-no-header-for-it-and-a-fix-is-authored-in-the-session.md)).
_Avoid_: Authoring agent, writer agent, phase agent
Phase Record: The append-only record under Roundfix Home, in the directory `phase-record`, of which Spec and Supervisor Phase each Supervisor session works on and which Work Item each prompt of a Run or of a pre-PR review served. It also holds fallback entries naming an Authoring Fallback, the declared model and effort, the selected model and effort, and the limit line that caused the switch. It is a set of day files named by the UTC date, one JSON object per line under the schema `roundfix/phase-record/v1`. An entry holds identifiers and times; an entry of an Authoring Phase also holds the model and reasoning effort that ran it, how each was learned, whether its Author Subagent or the session ran it, and its Repository Identity. It never holds prompt text, a token count or a price; no line is rewritten, and the Run Retention Sweep removes a day file older than its cutoff ([ADR-0407](docs/adr/0407-a-phase-record-names-the-spec-and-phase-of-supervisor-work-and-a-phase-boundary-ends-the-session.md), [ADR-0418](docs/adr/0418-a-phase-entry-holds-the-model-and-reasoning-effort-that-ran-an-authoring-phase.md)).
_Avoid_: Usage log, phase marker, session journal
