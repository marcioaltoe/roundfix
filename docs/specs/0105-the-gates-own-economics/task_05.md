## Work

- The task-authoring skill carries the characterization obligation: a Spec whose
  work crosses an external surface — an adapter, a contract, a database —
  authors a Task that records what the real boundary does, and that Task
  precedes the work depending on it. A premise the boundary does not support
  then fails on day one rather than after four Runs.
- The task-execution skill states what a characterization Task requires of the
  Agent performing it: record what the real thing does, not what a fake does.
- The QA gate skill applies the equivalent-evidence path to the Pull Request row
  by default. That row is unreachable by construction, so each Spec paying to
  rediscover the arrangement is the cost this removes — one Spec paid six of its
  eight gate executions for that row alone.
- The row is neither a silent pass nor a block: the evidence must be recorded.
  A row with no recorded evidence stays blocked exactly as today.
- Read every claim from the delivered behavior, not from the TechSpec draft.
  Where the two disagree, the delivered behavior is the fact and the TechSpec is
  corrected.
