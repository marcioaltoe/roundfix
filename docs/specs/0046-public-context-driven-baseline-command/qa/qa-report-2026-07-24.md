# QA report — Public Context-Driven Baseline Command

## Scope and environment

This full workspace-contained gate covers every PRD User Story, Core Feature,
Success Metric, applicable Non-Goal, and Task acceptance-criterion group on
the current Run Worktree build. The intended actors are repository
maintainers, automation authors, Agents following the shipped skill, Roundfix
users, and release verifiers.

The public surface is the built `roundfix` binary. Disposable Git repositories
provide real plan/apply, failure, recovery, and formatter-composition
journeys. The repository gate is `rtk make verify`.

The live Fluxus journey is a separate authorization boundary in the PRD and
Task 17. This invocation does not name or authorize that external repository.
The row starts pending with the rest of the matrix and can pass only with
separate authorization and live evidence.

Task acceptance rows below are composite credit rows. A row passes only when
the current static gate passes and every checked acceptance criterion in that
Task has named, reproducible evidence in its `## Result`; otherwise the row
fails or is blocked.

High-risk probes are stale confirmation, consulted-input drift,
mutation-target drift, unrelated clone lineage, unsafe carriers, injected
post-write failure, interrupted transaction recovery, repeated revision, and
empty reapply. They target unauthorized mutation, lost policy, rollback, and
replay risk.
