## Findings

### QA-001 — Publication Preflight cannot detect two required identity states

- Impact: Trust-Damage.
- Actor and step: maintainer, Publication Preflight before cross-compilation.
- Expected: PRD Core Feature 2 requires the preflight to detect missing package
  ownership or trusted-publisher configuration before any publish.
- Actual: `CLASSIFY_JQ` receives only the public packument's `.versions` and
  `.time`; any existing coordinate with an unused version is `eligible`,
  regardless of ownership or trusted-publisher configuration. The TechSpec and
  ADR-0084 acknowledge that npm offers no read-only identity proof, but the PRD
  promise was not removed or marked deferred.
- Reproduction: inspect the classifier in `.github/workflows/release.yml` and
  run `workflow_probe.rb`; `eligible.json` passes without any ownership or
  trusted-publisher datum.
- Evidence: `workflow_probe.rb`, `_prd.md` Core Feature 2, `_techspec.md`
  Executive Summary and Risks.
- Affected rows: 13.

### QA-002 — Publish failure attribution labels every first failure as identity

- Impact: Trust-Damage.
- Actor and step: diagnosing maintainer, first `npm publish` for a coordinate.
- Expected: Story 3 requires the failure to identify whether identity or
  registry state blocked publication and to name the coordinate.
- Actual: any nonzero first `npm publish` result enters the `identity:` branch.
  A simulated registry network timeout was labelled `identity:` and retried
  with the token; the second failure returned only npm's raw error.
- Reproduction: run `rtk ruby
  docs/specs/0058-npm-trusted-publishing-and-release-preflight/qa/evidence/2026-07-31-qa-01/failure_attribution_probe.rb`.
- Evidence: `failure_attribution_probe.rb`, `command-log.md`.
- Affected rows: 14.

### QA-003 — Runbook omits the registry-side token-publication shutdown

- Impact: Trust-Damage.

  long-lived token and token publication to be disallowed for all owned
  packages.
- Actual: the runbook removes the repository variable, `NPM_TOKEN` secret, and
  fallback branch, but never tells the maintainer to disallow token

- Reproduction: run `rtk ruby
