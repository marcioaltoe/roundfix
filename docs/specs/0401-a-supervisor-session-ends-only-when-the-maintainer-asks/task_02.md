# Task 02: The autonomous-work clause says no phase of a Spec ends the session

## Overview

The `autonomous-work` Baseline clause that tells a supervising session when
to end says that no phase of a Spec ends it, with or without a person
present, and that it ends only when the user asks or the work stops. Its
first three sentences, which make a turn arm something that outlives it,
stay. The clause keeps its identity and force. The derived Baseline files
are regenerated by their commands, and this repository's managed
`docs/agents/autonomous-work.md` is refreshed with the sanctioned
`baseline update`, after which a second refresh reports `current`.

## Requirements

1. MUST change, in `internal/baseline/assets/modules/autonomous-work.json`,
   only the `guidance` of `clause.autonomous.loop-07-outlive-the-turn`, to
   the text of `_techspec.md` → API Contract 3, word for word.
2. MUST keep the clause's id, its `mandatory` `enforcement`, its rule, its
   absence of `replaces` and its first three sentences, and MUST add or
   remove no clause and no rule (`_techspec.md` → invariant 5).
3. MUST regenerate, in this order and never by hand: the module record with
   `go test ./internal/baseline -run '^TestEveryBaselineModuleVersionIsRecorded$' -record-module-versions -count=1`
   (it writes the next version of the module; the Spec names no number);
   the derived Baseline files with `make baseline-digests`; and, as the
   Task's last step, this repository's managed guide with
   `go run -buildvcs=false ./cmd/roundfix baseline update --repo . --no-skills --no-history --yes --format text`,
   whose second run reports `current`. The files these commands rewrote in
   the measurement of `_tasks.md` are declared below; any other file they
   rewrite on the tree the Task runs on is recorded by the Daemon.
4. MUST rename `TestTheOutliveTheTurnClauseStatesThePhaseBoundary` in
   `internal/baseline/phase_boundary_clause_test.go` to
   `TestTheOutliveTheTurnClauseStatesWhenASessionEnds`, keeping its checks
   of the clause's id, enforcement and absence of `replaces`, and make its
   phrase table hold, each exactly once in the clause, the Standard
   TypeScript golden and this repository's guide:
   - the three it holds today for the turn:
     `must_arm_something_that_outlives_its_turn`,
     `never_end_a_turn_stating_work_will_continue` and
     `when_no_mechanism_is_armed_say_what_remains`, with their phrases;
   - `session_handoff_names_boundary_state` and
     `user_is_told_what_stays_armed`, with their phrases;
   - `no_phase_ends_the_session`: "No phase of a Spec ends the session,
     whether a person is present or not";
   - `the_session_goes_on`: "after an authoring phase, a delivery or a
     release, the session goes on with the next queued work";
   - `authoring_skill_says_where_it_runs`: "each authoring skill says when
     a phase runs in a subagent with its own context";
   - `the_session_ends_when_asked_or_stopped`: "The session ends only when
     the user asks or the work stops because nothing remains or what
     remains waits on the user".

   It MUST drop `phase_boundary_is_recorded`, `no_further_phase_starts` and
   `wake_up_stays_in_the_session`, and MUST add the subtest
   `no_old_boundary`, asserting in the same three places that "after each
   authoring phase", "start no further phase in that session" and "the way
   across a boundary" each occur zero times.
5. MUST NOT change, by hand or by command, any other module, any template,
   Source Baseline, Setup Snapshot or profile other than
   `standard-typescript-monorepo.json`, `AGENTS.md`, `CLAUDE.md`,
   `docs/agents/specific-repository.md`, `.roundfixrc.yml`, the Makefile, a
