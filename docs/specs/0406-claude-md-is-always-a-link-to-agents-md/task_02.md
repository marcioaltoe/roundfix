# Task 02: Every Baseline plan makes CLAUDE.md the link to AGENTS.md when nothing is lost, and the guide says so

## Overview

Adoption writes `CLAUDE.md` as a symbolic link to `AGENTS.md`, and a managed refresh does so when the file holds nothing of its own. Otherwise the plan warns and leaves the file. The file transaction replaces a regular file or a link at that one path and restores it on rollback. The `agent-instructions.md` guide template states the rule, the derived Baseline files are regenerated by their commands, and this repository's managed guide is refreshed with the sanctioned `baseline update`. ADR-0100 records the amendment.

## Requirements

1. MUST implement `_techspec.md` → invariants 5 to 8 and API Contracts 1 and 2 in `internal/baseline`:
   - `assemblePostimages` in `plan.go` reads the shape with `ReadClaudeInstructionLink`, through the plan's Git runner;
   - it adds the link postimage `{Path: "CLAUDE.md", Kind: "symlink", Mode: 0, Content: "AGENTS.md"}` with no content identity, and one managed entry `root.claude-instruction-link` of kind `link`, as invariant 5 decides;
   - in a managed refresh that replaces a regular file it also writes the root backup `CLAUDE.<digest>.md` through the backup path adoption uses, with its `backup:CLAUDE.md` entry, and `expectedRootBackups` in `apply.go` accepts it;
   - otherwise it adds the warning of invariant 6, with the code and message of API Contract 2 word for word, to the plan's warnings;
   - `validateManagedRefreshPreservation` accepts the link postimage at `CLAUDE.md` only when the reader, run on the preimage, finds the file convertible, and keeps refusing every other change outside Managed Regions;
   - `preimageMatchesPostimage` in `apply.go` matches a link postimage against a link preimage with the same target.
2. MUST let the file transaction in `transaction.go` replace a regular file or a link at `CLAUDE.md`, and only there, with the planned link, as invariant 8 says. This covers the journal validation, `captureTransactionEntries`, `validateTransactionPostimages`, `replacePostimage` and `restoreTransactionPreimage`. A rollback removes the link only when it is still the planned one, then restores the regular bytes and mode, or the previous link's target. Every other path keeps refusing a link postimage over an existing preimage.
3. MUST change the helper `assertAppliedPostimage` in `internal/baseline/apply_test.go` so it compares a link postimage with the link on disk, by kind and target. Its regular-file comparison MUST stay as it is, so `TestApplyExactDigest` passes with the link in the plan.
4. MUST add `internal/baseline/claude_link_plan_test.go` with these tests, each calling `t.Parallel()` first and building temporary Git repositories:
   - `TestBaselinePlansTheClaudeInstructionLink`. It has the subtests `adoption_greenfield_absent`, `adoption_greenfield_file`, `adoption_preservation_file`, `adoption_import_line`, `adoption_link_elsewhere`, `adoption_unlinked_checkout_left`, `refresh_absent_created`, `refresh_empty_file_converted`, `refresh_import_line_converted`, `refresh_managed_regions_only_converted`, `refresh_copy_of_agents_converted`, `refresh_link_to_clean_file_converted`, `refresh_file_with_a_rule_withheld`, `refresh_link_to_file_with_a_rule_withheld`, `refresh_unlinked_checkout_left`, `refresh_link_kept` and `stale_claude_md_refuses_apply`. Each asserts:
     - the `CLAUDE.md` postimage, or its absence;
     - the managed entry, the file change action and the whole warning;
     - for adoption and for a managed refresh, the backup `CLAUDE.<digest>.md` of a replaced regular file with its bytes, and no backup for a replaced link;
     - after the apply, that `CLAUDE.md` is a symbolic link whose target is exactly `AGENTS.md`, or that its bytes and mode are unchanged;
     - for every conversion, that the next plan reports the repository current.
   - `TestClaudeInstructionLinkRollbackRestoresTheFile`, with the subtests `regular_file` and `link_elsewhere`. Each injects a fault through the transaction's phase hook after `CLAUDE.md` was replaced, and asserts the original bytes and mode, or the original target.
5. MUST change `internal/baseline/assets/templates/guides/agent-instructions.md` as `_techspec.md` → API Contract 4 says, word for word. It MUST raise by one the template's `version` in `templates/index.json` and the `version` of `guide.agent-instructions` in `internal/baseline/assets/modules/core.json`, and change no clause, rule or other template.
6. MUST add to `TestBaselinePlansTheClaudeInstructionLink` the subtest `guide_states_the_rule`. It asserts that the Standard TypeScript formatter golden `docs/agents/agent-instructions.md` holds the sentence of API Contract 4 once.
7. MUST regenerate, in this order and never by hand:
   - the module record, with `go test ./internal/baseline -run '^TestEveryBaselineModuleVersionIsRecorded$' -record-module-versions -count=1`, which writes the next `core` version;
   - the derived Baseline files, with `make baseline-digests`, which also rewrites the four plan goldens with the link;
   - as the Task's last step, this repository's managed carriers, with `go run -buildvcs=false ./cmd/roundfix baseline update --repo . --no-skills --no-history --yes --format text`, whose second run reports `current`.

   The files these commands rewrote in the measurement of `_tasks.md` are declared below. Any other file they rewrite on the tree the Task runs on is recorded by the Daemon.
8. MUST change, through `domain-modeling`, the glossary entry **Managed Refresh** in `CONTEXT.md` to say that it may replace the root `CLAUDE.md` with the Claude Instruction Link when the file holds nothing of its own, writing the root backup of a replaced regular file, citing ADR-0432.

MUST NOT change, by hand or by command, any Source Baseline, Setup Snapshot, profile other than `standard-typescript-monorepo.json`, the formatter golden `AGENTS.md`, `docs/agents/specific-repository.md`, `internal/baseline/plan_test.go`, `.roundfixrc.yml`, the Makefile, a workflow, `go.mod` or a lint configuration. ## Acceptance Criteria

- [ ] Every adoption fixture ends with `CLAUDE.md` the link and every replaced file backed up; an unlinked checkout is left and warned about.
- [ ] Every convertible refresh fixture ends with the link and a current second plan; every other one is byte-identical with the exact warning.
- [ ] A fault after the replace restores the original file or link, and a changed `CLAUDE.md` refuses the apply.
- [ ] The guide carries the rule for every profile, the derived files and this repository are current, and the Baseline and CLI suites pass.
- [ ] Removing the preservation exception makes `refresh_import_line_converted` fail.
