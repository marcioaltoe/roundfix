# Sanctioned digest regeneration is fallout of the authorized edit

Editing a Roundfix-owned Skill deterministically changes derived digest pins
across the Baseline catalog setups, the normalized catalog snapshot, and the
parity corpus, and requiring separate express authorization for that fallout
turned every authorized Skill edit into a governance amendment that stranded
its own Task. Derived pins regenerated by the sanctioned regeneration command
are therefore deterministic fallout of the expressly authorized Skill edit and
need no separate per-Spec authorization; hand-edited pin values remain
unauthorized mutations, and the QA gate keeps auditing that regenerated
values match the canonical sources. Widening Task authorization boundaries
instead was rejected — the authorization stays drawn around the cause (the
Skill edit), with its computable effects following it.
