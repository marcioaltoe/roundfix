# ADR-0060: Source Baselines are exhaustive and project-agnostic

A Source Baseline must be project-agnostic and independently account for every Normative Clause, recommendation, and Operational Contract before a transition or Baseline Readoption can mutate a repository. Project-specific instructions remain in typed repository documents or Repository-Specific Normative Rules; raw project corpora never ship as setup assets.
