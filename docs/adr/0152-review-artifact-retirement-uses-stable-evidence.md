# Review Artifact retirement uses stable evidence

Proposed replacement for ADR-0123: classify Review Artifact retirement from stable recorded or provider evidence, keeping unknown evidence explicit instead of treating local object availability as lifecycle proof. Relocating legacy review paths is independent of that classification, and squash delivery requires its recorded outcome rather than ancestry alone. ADR-0123 remains operative until this proposed policy is approved; this record authorizes no migration.
