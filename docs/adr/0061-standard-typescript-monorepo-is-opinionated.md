# ADR-0061: Standard TypeScript Monorepo is an opinionated profile

The Standard TypeScript Monorepo Profile requires the complete confirmed TypeScript, Bun, React, Hono, data, UI, quality, and observability stack instead of presenting a minimally portable menu. Missing required capabilities block readiness, while explicitly optional or recommended capabilities retain their weaker enforcement so the profile stays predictable without inventing repository state.
