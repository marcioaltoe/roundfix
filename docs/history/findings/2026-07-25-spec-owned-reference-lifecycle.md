# Spec workflow — adopted source documents must travel with their owning Spec (2026-07-25)

The repository describes inbox-to-finding-to-Spec promotion as the normal document lifecycle, but promotion currently creates links without transferring the source document. A Spec can therefore be complete and archived while the evidence that shaped it remains in a separate lifecycle with links that no longer resolve.
