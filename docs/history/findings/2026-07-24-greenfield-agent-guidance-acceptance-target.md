# Context-Driven Baseline — greenfield guidance acceptance target (2026-07-24)

A greenfield Baseline run against Fluxus produced the compact root and modular `docs/agents/` structure expected from the planned guidance work, but the live result still needed project rules to be redistributed from `docs/agents/specific-repository.md`. This finding records the accepted target for the two follow-up Specs: generated guidance must be self-contained, must not depend on an ADR being present, and must propagate applicable project constraints into every new Spec.
