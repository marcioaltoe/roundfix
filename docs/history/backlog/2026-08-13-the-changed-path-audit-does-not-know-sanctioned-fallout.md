# The changed-path audit does not know sanctioned fallout

ADR-0081 settles that derived pins regenerated by the sanctioned command are deterministic fallout of an expressly authorized edit and need no separate authorization. The QA gate's changed-path audit does not implement that: it reads the authorization record's exact `paths` and refuses any changed file absent from it, including the derived artifacts the authorized edit necessarily regenerates.
