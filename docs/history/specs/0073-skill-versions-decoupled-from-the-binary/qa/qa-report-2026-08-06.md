### F-001 — Owned-Skill edit can fail the exact gate on queued-verification cancellation

- Impact: `Blocks-Completion`.
- Actor and step: Roundfix maintainer, Q-12, after editing owned Skill content
  without a regeneration step.
- Expected: the integration journey's exact nested `make verify` exits 0.
- Actual: it exited 2 because
  `TestTaskCycleVerificationCapacityCancellationWhileQueuedStartsNoCommandOrSettlement`
  observed two Verification starts where only the active one may start.
- Reproduction:
  `rtk proxy env GOCACHE=/private/tmp/roundfix-qa-0073-integration-cache go test -tags=integration ./skills -run '^TestOwnedSkillEditLeavesMakeVerifyGreen$' -count=1 -v`.
- Diagnostic follow-up: the failing test passed 20 isolated repetitions and
  the full `internal/daemon` package passed 10 repetitions at parallelism 16.
  The failure is load-sensitive; the evidence does not prove an environmental
  cause, so it remains a code finding rather than a blocked row.
- Evidence:
  [`focused-contracts-and-integration.md`](evidence/2026-08-06-spec-0073/focused-contracts-and-integration.md).
- Affected rows: Q-12.

### F-002 — Three dispatched external Go Skills have no recorded provenance

  provenance contract after the 2026-08-02 additions.
