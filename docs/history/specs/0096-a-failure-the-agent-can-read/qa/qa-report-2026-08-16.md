## Findings

### F-001 — Verification failure cause is replaced by `<nil>`

- Impact: Trust-Damage.
- Actor and step: an Agent receives Verification Feedback, or a Supervisor reads
  the Batch result, after a Verification command exits nonzero.
- Expected: the feedback and terminal reason retain the verifier's cause, such as
  `exit status 7` or `tests failed`.
- Actual: the production path reports `verification failed: <nil>`.
- Reproduction:
  `rtk env GOCACHE=/tmp/roundfix-0096-qa-gocache go test -count=1
  ./internal/daemon -run
  '^(TestResolveCycleVerificationFailureFailsBatchAndContinues|TestRunOutcomeDerivedFromUnresolvedIssues)$'
  -v` exits 1 with both assertions receiving `<nil>`. The focused CLI journey
  `TestRunResolveVerificationFailureDoesNotCommit` exits 1 after the public
  progress line reports the same value.
- Root cause: in `internal/daemon/engine.go`, `metadata, err :=
  req.publishFailedCommand(...)` shadows the nonnil verifier error. The returned
  outcome then formats that publisher error after it has succeeded, so the value
  is nil. This change landed in task_03's commit `a3f23312`.
- Affected rows: QA-01 and QA-07.

### F-002 — OpenCode warm-session fixture is nondeterministic in the full gate

- Impact: Friction.
- Actor and step: a maintainer runs the authoritative repository Verification.
- Expected: the fake warm-session idempotence check is deterministic under the
  repository's declared parallel test command.
- Actual: the full gate failed once while applying the fake OpenCode selection;
  the exact focused test then passed five consecutive runs.
- Reproduction: `rtk make verify` failed
  `TestACPXRunWarmSessionIsIdempotent`; `rtk env
  GOCACHE=/tmp/roundfix-0096-qa-gocache go test -count=5 ./internal/agent -run
  '^TestACPXRunWarmSessionIsIdempotent$' -v` exited 0.
- Root cause: unknown. The isolated evidence rules out a deterministic failure in
  that test but does not settle interference in the parallel suite.
- Affected rows: none; it independently keeps the repository gate red.
