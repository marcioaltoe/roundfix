## Findings

### F-001 — Gate-only inputs do not reach the production QA pipeline

- Impact: `Blocks-Completion`.
- Actor and journey: Supervisor running a Spec's authored terminal gate; R04 and
  R05 before matrix execution.
- Expected: the gate classifies its Spec-owned vocabulary finding as a named
  repair input, maps Task-named repairs and exact paths into the mechanical
  request, performs them, verifies them, and records them.
- Actual: `GatePrecondition` has no production caller. The production
  `qaMechanicalRequest` supplies neither `TaskRepairPaths` nor
  `AssignedRepairs`, and `spec.Task` parses no repair declaration. Direct unit
  callers pass while the real request contains two empty slices.
- Reproduction: run the public vocabulary fixture command from R04, then run
  `TestQAProbeTaskAssignedRepairReachesMechanicalRequest` from the current-source
  scratch copy named in R05. The first exits `1`; the second fails with both
  request slices empty.
- Required change: connect the gate-specific precondition classification to the
  real gate boundary, define and parse the Task repair declaration, populate the
  mechanical request, and add a TaskCycle-level regression that proves the Task
  file drives the bounded write and report row.
- Affected rows: R04 and R05.

### F-002 — Assigned Repair is emitted but absent from the domain contract

- Impact: `Trust-Damage`.
- Actor and journey: maintainer reading the gate's new repair records; R08.
- Expected: the stable repair concept emitted by the report and exported by the
  backend has one canonical glossary definition and a complete TechSpec
  Vocabulary Contract.
- Actual: the source exports `AssignedRepair`; the report emits performed and
  failed assigned-repair sections; neither `CONTEXT.md` nor a TechSpec
  Vocabulary Contract owns the term. The strict checker skips the missing
  contract instead of verifying it.
- Reproduction: compare `internal/speccheck/mechanical.go` and
  `internal/speccheck/report.go` with `CONTEXT.md`, then run the strict JSON check
  from **Static gate**.
- Required change: declare the emitted repair vocabulary in the TechSpec and add
  its canonical meaning to `CONTEXT.md` through the repository's domain-modeling
  contract.
- Affected row: R08.
