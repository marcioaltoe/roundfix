82: ## Tests run through the package script, never through `bun test`
83: 
84: - **mandatory**: Run tests with `bun run test`, which executes the package's `test` script and
85:   therefore Vitest. `bun test` invokes Bun's own test runner instead, and this repository's suites are
86:   written for Vitest. The script also carries the repository's flags (`--silent --reporter=dot`), so a
87:   hand-built runner command silently drops them.
88: 
89: - **mandatory**: Never use `bun test` in a Task's `## Verification`. The two runners disagree on the
90:   same unchanged file, so a Verification built on `bun test` settles Tasks on a false verdict. The
91:   measurement behind this rule was taken in a sibling repository on the same stack; the runner
92:   behavior it describes is not repository-specific.
93: 
94: ```bash
95: rtk bun run --cwd packages/backend test                          # whole package suite, from the root
96: rtk bun run --cwd packages/backend test src/path/to/file.test.ts # one file
97: rtk bun run --cwd packages/backend test src/path -t 'case name'  # filtered
98: make test                                                        # every package, through Turbo
99: ```
