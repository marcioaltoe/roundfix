## What shipped

**0055 — owner identity without fork.** `processStartIdentity` no longer forks
`/usr/bin/ps`. Linux reads `/proc/<pid>/stat` field 22 counted from the last
`)`; macOS reads `KERN_PROC_PID` through `golang.org/x/sys/unix`. Tokens gained
a `linux:`/`darwin:` prefix, so a token written by the old `ps` implementation
classifies as *unreadable* rather than as a false mismatch — the migration fell
out of the feature as designed. `ErrOwnerIdentityUnreadable` now separates
"the host could not answer" from a proven mismatch, which still refuses
absolutely. Schema v12 adds `owner_identity_unproven`, so a Run created without
reuse protection warns once and is visible in `roundfix runs list`.
`roundfix stop <run-id> --force` finally accepts its trailing flag.

**The predicted side benefit landed.** The `fork/exec /bin/ps: operation not
permitted` row that appeared as an environment block in every QA run in this
repository is gone.

**0060 — Spec-owned reference lifecycle.** `write-prd` owns an adoption
transition that moves adopted inbox notes and findings into
`docs/specs/<slug>/references/` with `git mv`, records provenance in
`_index.md`, and flips a finding to `done` before the move. `archive-spec`
gained a self-containment precondition that `qa_override: true` cannot bypass.
The gate applies only to Specs carrying an index, so no historical archive
turns red.

## What cost the time, and what did not

Both Specs' Task Graphs implemented in about 25 and 25 minutes of Run time.
The expensive parts were review (0060 took 3 rounds and 13 issues) and the
pre-Run Spec corrections below.

Preflight rejected Spec 0055 **twice before creating a Run**, which is the
cheapest possible place to learn it:

1. `task_04` declared `type: cli`. Allowed Task Types are backend, frontend,
   data, infra, docs, test, chore. There is no `cli` type; CLI argument work is
   `backend`.
2. `task_05` listed `docs/user-guide/` as an interface path. Context paths must
   be clean **file** paths, not directories.

Neither failure is discoverable by reading the Spec. **Run
`roundfix implement --spec <slug>` early** — preflight validates the whole Task
Graph and creates nothing when it rejects.

## Traps this session hit

1. **A Verification that passes on an empty tree cannot prove work happened.**
   Spec 0060's `task_03` settled `completed` having run none of its four
   archive-gate cases. Its R1 forbade committing rehearsal fixtures while its
   R2 required `git log --follow` to reach pre-adoption commits — and
   `--follow` only reads committed history. Its Verification was `make verify`
   plus an empty `git status --porcelain`, both of which pass *most easily*
   when nothing was done. Recorded in
   `docs/findings/2026-07-31-a-rehearsal-task-can-settle-completed-without-rehearsing.md`.
   The QA session independently rebuilt the rehearsal and covered every case,
   so the behavior is proven — one layer later than intended.
2. **A heavy review invalidates the QA evidence.** QA ran against 0060's build
   `00ca18e`; review then rewrote `archive-spec/SKILL.md` by 157 lines,
   including three real bypass vectors. The in-Run `--qa` exemption is about
   whether the QA *matrix* observes the Pull Request — it says nothing about
   whether review will change the artifact QA validated. When a review lands
   substantive changes, re-verify the changed logic directly or request the
   gate again.
3. **`roundfix archive` needs an unscoped commit subject.** Still true:
   `cog.toml` sets `scopes = []`, so `chore(specs): archive <slug>` is
   rejected. Use `chore: archive <slug>`. The archive command itself moves the
   files and exits 0 without committing.
4. **`roundfix doctor` exits 1 on a missing external skill**
   (`knowledge-workspace` absent from `skills-lock.json`). It does **not**
   affect `make verify` or Run preflight — the gate's `skills-check` covers the
   Roundfix-owned bundle only. Unrouted; fix is
   `bunx skills add marcioaltoe/skills@knowledge-workspace`.
5. **A new binary refuses read-only commands against an un-migrated Run
   Database.** After 0055 added schema v12, `roundfix runs list` fails until an
   operational command migrates. Do not force a migration while a Daemon is
   running on the old schema; read the event stream instead.

## What the review caught that testing did not

CodeRabbit found three genuine bypass vectors in 0060's archive gate that a
green gate would never have surfaced: a symlinked `_index.md` masquerading as a
legacy pre-contract Spec, path traversal in the index's `path` column, and a
line-grep QA check that would accept `verdict: pass` beside a nonzero
`rows_blocked_finding` — contradicting the semantics Spec 0053 shipped.

It also proposed replacing 0055's darwin `SysctlRaw` + `unsafe.Pointer` with
`unix.SysctlKinfoProc`, which looks strictly safer and is **wrong here**:
`SysctlKinfoProc` returns `EIO` for a reaped PID, breaking the `ESRCH`
process-gone signal ADR-0044 relies on to reclaim orphaned locks. It was
triaged invalid with an empirical probe. Read rejections as carefully as fixes.
