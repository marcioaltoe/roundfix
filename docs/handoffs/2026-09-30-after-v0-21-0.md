## Operating notes

- Build the binary the queue owner runs from `main` right before
  `deliver start`. An owner started on an older binary keeps its defects for
  the whole queue.
- After widening a grant mid-delivery, rebase the item branch onto the `main`
  that contains it. The authorization audit reads the grant at the merge base
  of each Task commit.
- Carry forward (`reconcile <run> --carry-forward`) before committing any
  Spec amendment on an item branch, then `deliver retry`.
- Use `roundfix reopen --spec` to reopen a settled QA gate when a corrective
  Task is added.
- Never let a pipe hide a gate's exit status. Read `$?` of the check itself.
