# Gate-cycle cost — measured 2026-08-03

The gate's dominant cost is Agent work, not daemon bookkeeping. The latest
complete representative journal spends 615.771 of 625.710 seconds inside the
QA Agent session. The only repeated daemon work found without changing what
the gate observes was a second QA-directory scan after a missing report had
already been proven absent.

## Procedure

The end-to-end attribution uses the latest complete Spec 0057 gate journal in
the local Run Database:
`run_20260802T151023Z_fe336345b404c5b0`, Batch 003. The measured interval
starts when the preceding Task session closed at
`2026-08-02T15:41:33.681123Z` and ends when the QA Report commit event was
written at `2026-08-02T15:51:59.390807Z`. Tool-call start and terminal update
timestamps isolate `rtk make verify`; no duration below is an estimate.

The same-worktree before-and-after uses the existing production gate fixture,
which exercises pass, partial, fail, missing, and unreadable reports through
`TaskCycle`, Task settlement, daemon events, snapshots, and report commits:

```text
GOCACHE=<worktree>/.gocache go test ./internal/daemon -count=1 \
  -run '^TestTaskCycleQAVerdictMatrixSettlesRunAndCommitsReport$' -v
```

The focused missing-report measurement used a temporary benchmark around
`settleQAVerdict`; the benchmark file was removed after both runs. Each side
ran ten samples on the same Apple M4 Pro and task-local Go cache. The medians
below come from those samples.

## Dominant cost that stays

Agent-session inference and live QA work remain the dominant cost: 468.669
seconds, or 74.90% of the representative cycle even before counting the
static command it launches. This Task cannot shorten that work honestly.
Skipping scope derivation, public journeys, independent confirmation,
evidence capture, or report updates would change report content and verdict
semantics; reusing an implementation Agent session would conflict with the
separate QA-session contract. The microsecond missing-report trim removes
demonstrably repeated work, but it does not pretend to solve the minutes.
