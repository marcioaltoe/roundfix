## Findings

### QAF-001 — A queued Verification starts after a public Stop Request

- Impact: Trust-Damage.
- Actor and journey: user stopping an Implement Run, US8, after one Task is
  Verifying and another is Waiting for Verification.
- Expected: the waiting Task exits the queue promptly, starts no child
  command, receives no false terminal status, and remains resumable.
- Actual: after `roundfix stop` recorded the Stop Request, task_02 advanced
  from `waiting` cursor 12 to `started` cursor 15, ran its full 30-second shell
  command, passed, and settled `completed`; the Run reached `Stopped` only
  after both Tasks completed.
- Reproduction and evidence:
  `qa/evidence/2026-07-28-spec-0042/public-cancellation-flow.md`.
- Affected rows: 10; PRD US8, Core Feature 9, and the queued-cancellation
  Success Metric.

### QAF-002 — Attach help advertises a rejected flag order

- Impact: Friction.
- Actor and journey: Supervisor following the built CLI help for Attach.
- Expected: `roundfix attach <run-id> --no-input`, the order printed by root
  help and Attach help, replays the named Run.
- Actual: the command exits 2 with
  `roundfix attach failed: unexpected argument "--no-input"`.
  Moving the flag before the Run ID or omitting it succeeds.
- Reproduction and evidence:
  `qa/evidence/2026-07-28-spec-0042/cli-contract.md`.
- Affected rows: 12 and 16.

### QAF-003 — Task 03's historical direct-gate selector is stale

- Impact: Friction.
- Actor and journey: QA Agent reproducing Task Result evidence.
- Expected: the declared
  `TestVerificationGate.*(Exclusive|Fair|Cancel|Release)` command runs the
  stated fairness/cancellation cases.
- Actual: it exits 0 with `[no tests to run]` on the assembled build because
  later Tasks consolidated the cases under TaskCycle names.
- Mitigation in this gate: QA did not credit the stale selector; current
  TaskCycle integration, public CLI, repeated, and race evidence covered the
  acceptance criteria.
- Evidence:
  `qa/evidence/2026-07-28-spec-0042/project-constraint-audit.md`.
